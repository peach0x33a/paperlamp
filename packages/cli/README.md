# paperlamp

纸灯 / Paperlamp 的命令行工具：把组件源码复制进你的 Vue 3 + Tailwind CSS v4 项目，源码归你所有、随你修改。

文档与组件一览：<https://peach0x33a.github.io/paperlamp/>

```bash
npx paperlamp@latest init              # 写入主题、cn() 工具与 paperlamp.json，并安装依赖
npx paperlamp@latest add button card   # 复制组件及其依赖的组件
npx paperlamp@latest list              # 列出全部组件
```

在文档站的「构建」页调好基色、主题色、字体与圆角后，用 `init --preset <code>` 应用。
